# 🍕 Pizza Sales Analysis Using SQL

## 📌 Project Overview

This project analyzes Pizza Hut sales data using SQL to uncover business insights, customer purchasing behavior, and revenue trends. The analysis helps identify top-performing products, sales patterns, and opportunities for business growth.

## 📊 Dataset

The analysis is based on the following datasets:

- orders.csv
- order_details.csv
- pizzas.csv
- pizza_types.csv

## 🛠 Tools Used

- SQL
- Microsoft Excel
- Microsoft PowerPoint

## 📈 SQL Analysis Performed

This project includes SQL queries to answer key business questions:

1. Total Orders
2. Total Revenue
3. Best-Selling Pizzas
4. Revenue by Pizza Category
5. Revenue by Pizza Size
6. Peak Ordering Times
7. Daily Sales Trends
8. Top Revenue-Generating Pizzas
9. Category-Wise Sales Performance
10. Customer Ordering Patterns
11. Revenue Contribution Analysis

## 🔍 Key Insights

- Identified top-performing pizza categories.
- Analyzed customer ordering patterns.
- Measured revenue contribution by pizza type.
- Evaluated daily and hourly sales trends.
- Determined peak business hours.
- Identified highest revenue-generating products.

## 💡 Business Recommendations
